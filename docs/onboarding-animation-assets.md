# Onboarding animation asset review

The tour currently uses an original, inline SVG guide with short GSAP reactions and a small confetti burst. No third-party LottieFiles animation has been copied into `public/` or bundled with the app. Review these candidates before selecting any asset for the tour.

| Reaction | Candidate | Creator | Listing size | Listing license |
| --- | --- | --- | --- | --- |
| Wave | [Waving Character](https://lottiefiles.com/free-animation/waving-character-TjnPV99UqN) | LottieFiles community creator | 6.7 KB optimized dotLottie; 7.3 KB dotLottie | Lottie Simple License |
| Point | [Pointing Finger Animation](https://lottiefiles.com/free-animation/pointing-finger-animation-UjtVknxhdo) | Kartik Choudhary | 40.4 KB | Lottie Simple License |
| Celebrate | [Celebration](https://lottiefiles.com/free-animation/celebration-fM2BP3az2p) | Sue | 18.5 KB dotLottie | Lottie Simple License |

LottieFiles describes its Lottie Simple License as permitting free commercial use, modification, and distribution in products; attribution is not required but is encouraged. It prohibits redistribution as standalone animation files and resale of the original files. The site also says to check each animation's specific license and any creator restrictions. Before adding a selected animation, review the linked listing and the [current license guidance](https://help.lottiefiles.com/animation-licensing-basics-). These candidates have different illustration styles, so confirm that they fit the NiCE brand together before use.

If selected, prefer the optimized dotLottie version for the character reactions, play each once per tour step, and keep a static fallback for reduced-motion users. The existing confetti burst is generated locally and does not require a Lottie asset.
